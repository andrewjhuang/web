# Founders Farmstand — concept website

A farm-to-table cafe concept for Stanford's O'Donohue Family Educational Farm, redesigned from the team's mockup with a 1939 San Francisco Bay World's Fair (Golden Gate International Exposition) look: amber towers and star curtains, souvenir-menu border stripes, hand-tinted postcard photos.

**Pages** (hash routes, so every link works on any static host): Home, Souvenir Menu, Order Online → My Order → confirmation, Locations (map), The Farm (growers), Events (RSVP), Our Story, Catering & contact.

**Locations:** Stanford and Menlo Park from the mockup, plus new coastal cafes in Half Moon Bay (Princeton harbor) and Pacifica (Rockaway Beach) with coast-only dishes. Coastal addresses are fictional.

**Menu:** about 40 items across breakfast, toasts, bowls, plates, soups, bakery, coffee and tea, farm sodas, kids and a take-home market. Each item has ingredients, vendors and allergens, with dietary filters.

`?showcase` shows the live site in a desktop browser and a phone side by side, which is good for a portfolio embed. `?embed`-style hosts can also just load the site directly.

Food, farm and interior photos come from the team's mockup. A student design concept, not a real business.

npm install
npm run dev
