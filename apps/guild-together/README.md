# Guild — Grow in good company

An interactive prototype combining the three concepts from our Guild needfinding study of retail workers (Abigail DeLory, Andrew Huang, Hazel Jones):

1. **Welcome / Marketing rebrand.** Toggle Guild's current competitive copy ("compared to their colleagues") against a collaborative rewrite.
2. **About you.** Pick courses, interests, and weekly availability.
3. **Study Buddies.** Learners across the network are ranked by shared courses (50%), overlapping free time (30%), shared interests (15%) and same role (5%); see `src/match.ts`. Open a match to see your overlapping schedule and send an icebreaker.
4. **Coworker nomination.** Invite a coworker, preview what they receive, then fast-forward to them joining and enroll in shared courses together.
5. **Your circle.** Everyone you connected with, framed as collective progress rather than a leaderboard.

People shown are composites from our interviews. Not affiliated with Guild.

```bash
npm install
npm run dev      # local dev
npm run build    # typecheck + production build
```
