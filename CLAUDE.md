# Project conventions

- Each project is a standalone Vite + React + TypeScript app in `apps/<name>`, deployed as its own Vercel project with that folder as the root directory.
- Credits (footers, READMEs, captions) use **first names only**, e.g. "by Abigail, Andrew & Hazel". Never full names.
- Support `?embed` in every app to hide the credits footer and tighten padding for iframes.
- Mark concept work clearly: note it isn't affiliated with the real company and that data is simulated.
